# Name tracing examples v1

Original fictional-name worksheets (Emma / Alex), A4 and US Letter, generated locally from the same Canvas renderer used by the tool. No competitor artwork or user uploads.

Frozen renderer: `2a11494c3ce8f802f07a11d3c3e672aaccf79f86`. Geometry: Full page, 8 rows, 48pt, guides on, 36pt nominal safety margin + 1pt raster inset; opaque 300dpi Canvas embedded in one PDF page. Exact sizes and SHA256: `lib/name-tracing/example-manifest.json`.

Lettering: unmodified Raleway Dots Regular v1.000, SIL Open Font License 1.1; font SHA256 `a35582c11e29d5d40bf5ed263f4be18c42264376b51b6b8a7a1b79252b853e09`. Source/license: `/fonts/name-tracing/v1/SOURCE.md` and `/fonts/name-tracing/v1/OFL.txt`. PDF contains raster lettering, no embedded font program.

Each preview is derived from its matching final PDF at 72dpi and embedded as a static PNG data URI under the existing CSP. These digital samples are not a physical-print validation.
